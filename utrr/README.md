# utrr：不确定转运时间下危险货物公铁联运路径优化

配套论文《不确定转运时间与运到时限下危险货物公铁联运路径优化》（拟投《交通运输工程学报》）的求解与实验代码。

- 模型：风险-成本双目标、带运到时限机会约束的四层网络（客户层—公路层—转运层—铁路层）路径优化
- 算例：新疆（乌鲁木齐/独山子/库尔勒/哈密）→ 长三角（上海/杭州/南京/合肥/宁波）真实铁路廊道，6 个 OD 对
- 算法：**BMLC**（Bidirectional Multidimensional Label-Correcting，双向多维标号修正），四策略为机会可行性剪枝、Pareto 支配剪枝、下界剪枝与双向汇合
- 产出：第 4 章全部表格（CSV + Markdown 三线表）与图 5—图 11（700 dpi PNG + TIFF）；图 1—图 4 为手绘示意图，另出真实路网附图 S1

## 数据源与口径

默认读取真实路网 JSON（`data/real_case_xj_yrd/network.json`，xj-yrd-v2），由 `src/core/real_case.py` 转换为四层网络：

- **OD 与需求**：6 个 OD 对，需求 6～24 个 **40 ft 箱**（OD1 至 OD6 依次 24、12、16、10、8、6 箱）。计费按元/箱口径，与黄丽霞 2017 的 95306 运价一致；TEU 只在必要处括注（1 箱 = 2 TEU）。
- **铁路层**：65 个真实车站、136 条有向弧（68 段双向），含兰新/北疆/乌鲁木齐枢纽联络线/南疆（吐库二线）/陇海/宁西/京沪/沪杭/萧甬/淮南/阜淮/京九/皖赣/宣杭/商丘枢纽联络线 15 条真实线路，单方向合计 7238.01 km。逐线里程与公开值对齐（兰新 1892、北疆 241、陇海 1759、宁西 1075.69、京沪 649 等），`build_network.py` 的 `LINE_META` 逐线断言。宁芜线因扩能改造未完工
- **公路层**：客户点与货场间接驳弧，按绕行系数 × 大圆距离估算。
- **转运层**：18 个货场（A 级 12 / B 级 6），按 OD 取发送端候选、中途转运与到达货场；`_in`/`_out` 成对并以通过弧连接。货场与所在车站同址，`station`/`facility` 字段记明所在车站与实际办理设施。
- 站点与线路的逐项核对结论见论文项目的《路网与算例设计新疆至长三角.md》附 B（原《路网最终核对报告》已合并）。
- `--data-source synthetic` 切合成算例（多货场、多走廊），仅用于 4.7 规模实验与回归测试。

### 运营参数（与论文 4.1 一致）

- **铁路服务类型 3 类**（`config.ServiceType`）：集装箱班列（成本系数 1.00，60 km/h）、普快班列（0.83，50）、快速班列（1.33，80），途中停时均为 0。成本系数取黄丽霞 2017 表 5-10；**风险系数按在途暴露时间口径**取基准速度与服务速度之比，即 1.33/1.60/1.00（运输风险与在途暴露时间成正比）。不用 κ≡η——否则风险与成本同比，服务类型维度在（风险, 成本）平面上塌成一条过原点的射线。
- **危险品 3 类**（`config.HazmatClass`）：第 3 类（成本 ×1.50，风险 ×1.00）、第 6 类（×2.00，×1.10）、第 8 类（×1.50，×1.20），乘在弧段成本与风险上（黄丽霞表 5-4）。
- **运价**（黄丽霞表 5-11，95306 口径）：铁路 680 元/箱 + 2.754 元/(箱·km)，运量分 0～10、10～20、20～40 箱三档，固定费率倍数 1.00/1.05/1.10、变动费率倍数 1.00/0.80/0.70，即 f(L)=b_k+a_k·L 分档线性；公路 675 元/箱 + 36 元/(箱·km)。q 按 OD 固定，档位不增加标号维度，式(5) 望远镜性质成立。
- **转运时间**：正态不确定变量 N(e,σ)，e 按公铁、铁铁、铁公取 8/4/8 h/批（黄丽霞表 5-12），σ=4 h 为算例设定；中转成本 500/200/500 元/箱，中转风险系数 1.0/0.5/1.0。
- **风险基础数据**（黄丽霞 §5.5.2(9)）：公路 0.25×10⁻⁶、铁路 0.11×10⁻⁶（1/(箱·km)），中转 422.61×10⁻⁶（1/次）；运输事故后果 POP 1.64×10⁵ 人，中转/暂存 6.25×10⁴ 人。
- **基准设定**：运到时限 D=98 h、置信水平 α=0.90、节点风险耦合系数 θ、ρ 为算例设定（论文正文不列值）。

## 模型要点（避免与概率论混淆）

采用刘宝碇不确定性理论，而非概率论：

- 正态不确定变量 ξ ~ N(e, σ)，分布 Φ(x) = 1 / (1 + exp(π(e−x)/(√3σ)))
- α 分位数：e + (√3/π)·σ·ln(α/(1−α))，可靠度分位系数 λ_α = (√3/π)·ln(α/(1−α))（Chebyshev 保守分支已删）
- 独立正态不确定变量相加 **σ 线性相加**（不是方差相加）
- 机会约束 M{T̃ ≤ D} ≥ α 等价于确定性线性约束 T₀ + Σμ*i·y_i + λ*α·Σσ_i·y_i ≤ D
- 弧段风险 r_ij = q·p_ij·E_ij·κ_k·ζ_s（事故概率 × 事故后果，公路无 κ_k）
- 节点转运风险 r_i = q·p_i^t·e_i^t·ζ_s·(1 + θμ_i + ρσ_i)，与停留时间期望、波动同时耦合
- 品类系数分两类：风险系数 ζ_s（1.00/1.10/1.20）乘在弧段/节点风险上，成本系数 χ_s（1.50/2.00/1.50）乘在公路/铁路成本上
- 节点占比与总风险统一按式(2) 含 ζ_s 的模型口径核算

标号 L = (i, R, C, T₀, μ, σ, d, S, P)：d 为累计铁路运距（分档运价按边际增量计费），S/P 由标号链回溯。支配判定按 d₁ ≥ d₂ / d₁ < d₂ 两支分别比较 C 与修正成本 W = C − q·χ_s·η_k·f(d) + q·χ_s·η_k·a_k·d。

**服务类型粒度**（`config.service_selection`）：`segment`（默认，与式(7b)(7c) 一致）逐铁路弧选择列车等级，换乘只能在货场完成，未经货场转运不得中途改乘；双向汇合要求两半程在汇合点服务类型一致。`path` 为整路径统一服务类型的对照口径。

**4.7 的三类校验**：消融各变体（BMLC+k）与完整枚举（≤52 节点）应给出完全一致的 Pareto 前沿；外部基准 WST 只覆盖凸包段（应漏非凸段的混编折中解）；Gurobi-MIP 应与 BMLC 前沿逐点一致。一致性按目标值集合（成本/风险/时间）判定，不比路径签名（等值最优路径可能不同）。
